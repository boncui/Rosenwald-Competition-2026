# Navier–Stokes Vector

Research base for the "AI solved Navier–Stokes" vector from [../docs/Vectors.md](../docs/Vectors.md).

**Research question:** which sectors, industries, research fields and kinds of work are *harmed*
by the September 2026 Navier–Stokes breakthrough — and, since the competition bans shorts and
derivatives, what long-only position (if any) that implies.

## The event, in brief

| Date | What |
|---|---|
| 2026-09-07 | Buckmaster (**NYU**) & Alpöge release an Anthropic-assisted result on the inviscid **Euler** case |
| 2026-09-08 | OpenAI: ~10,000 coordinated agents, **88 hours**, find a finite-time **singularity** in 3D Navier–Stokes, formalized in **Lean**. Forced construction. Prize not claimed |
| 2026-09-11 | Clay Mathematics Institute: "apparently settled" — explicitly *not* a verification or an award |

Still open: **unforced** 3D global regularity. Credit and verification are contested.

## The central distinction

This is a **pure-mathematics blowup proof, not a faster solver**. Working engineers never relied
on global regularity — they use RANS/LES turbulence closures and validated test data. So the
literal question ("who loses because Navier–Stokes was solved?") may return near-empty, and the
research is designed to report that if true.

The economically loaded event is the **method**: autonomous agents doing frontier analytical work
in 88 hours. Both readings are researched on separate evidence; [00_METAPROMPT.md](00_METAPROMPT.md)
forbids either from borrowing the other's conclusions.
